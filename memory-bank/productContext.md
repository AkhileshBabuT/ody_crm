# Odyssey — Product Context

## Target Users
Restaurant managers and operations staff who need a centralized dashboard to manage daily operations including orders, menu, customers, and business settings.

## Product Type
B2B internal operations tool — not a consumer-facing ordering app.

## UX Requirements
- **Dark mode default** — premium slate + amber palette, calming and professional
- High information density without feeling cluttered
- Interactive flows: modals/drawers for create/edit rather than page navigation
- Real product feel: not static mockups but functional interactive screens
- Strong visual consistency via centralized design tokens
- Clear hierarchy and spacing throughout

## Design Aesthetic
- Premium, high-end "Restaurant Ops" theme
- Warm backgrounds with soft emerald/sage accents for positive states
- Slate neutrals (HSL-based) for surfaces and text
- Amber accents for primary actions and highlights
- No generic AI clichés (neon purple, pink gradients)
- Smooth CSS transitions (150-300ms) for all interactive states
- WCAG AA compliance (4.5:1 contrast ratio minimum)

## Key Interaction Patterns
- Sidebar navigation on desktop → bottom tabs on mobile
- Split-view layouts for list + detail (Orders)
- Drawer panels for customer detail (CRM)
- Modal dialogs for create/edit flows
- Toast notifications for action feedback
- Skeleton loading states during data fetches
